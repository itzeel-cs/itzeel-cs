# 💫 About Me:
Soy desarrolladora de software con experiencia en desarrollo web y móvil utilizando PHP, JavaScript, Kotlin y SQL. He participado en el diseño e implementación de módulos de negocio, mantenimiento de aplicaciones, optimización de consultas y resolución de incidencias.

Me interesa seguir creciendo en el desarrollo backend, la arquitectura de software y el análisis de datos, creando soluciones eficientes, escalables y fáciles de mantener.
